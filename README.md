# 🚀 Featured Projects

## 🎯 [IPG — Injection Payload Generator](https://github.com/nalin9887/IGP-Tool)

**Python • FastAPI • React • TypeScript • Chrome MV3 • Burp Suite • SQLAlchemy**

A local-first offensive-security toolkit built to make injection testing more contextual and less dependent on static payload cheat sheets.

Instead of simply presenting a large payload list, IPG analyzes the page and helps determine **what to test, where to test it, and which payload is most relevant**.

### What it does

- Automatically discovers potential injection points
- Detects URL parameters
- Detects fields inside and outside traditional HTML forms
- Detects `contenteditable` regions
- Identifies hidden inputs
- Performs DOM-sink analysis
- Fingerprints technologies, frameworks, and JavaScript libraries
- Detects WAFs
- Scores and prioritizes potentially interesting fields
- Recommends context-aware payloads
- Supports controlled one-click payload insertion
- Integrates directly with Chrome and Burp Suite
- Works locally without telemetry

### Hybrid Intelligence

IPG is designed to support two approaches:

**Deterministic Mode**
- Curated payload library
- Rule-based analysis
- Context-aware scoring
- Works completely without AI

**AI-Assisted Mode**
- Adds LLM-assisted reasoning and payload recommendations
- Uses application context to improve suggestions
- Complements rather than replaces deterministic security logic

The objective is to keep the tool useful even when an AI model is unavailable.

> Built strictly for authorized security testing.

## 🎬 [VaultDeck](https://github.com/nalin9887/vaultdeck)

**Node.js • React • TypeScript • SQLite • FFmpeg • HLS.js**

A privacy-first, local-first media platform that turns folders, external drives, and local storage into a personal streaming library.

Think of it as a self-hosted media dashboard where **your files stay on your machine**.

### Highlights

- No mandatory cloud
- No account requirement
- No telemetry
- Local-first architecture
- Movies, TV, anime, music, photos, documents, and more
- Evidence-based media classification
- Adaptive HLS streaming
- FFmpeg-powered transcoding
- Reversible and journaled file operations
- External-drive and network-share support
- Windows, macOS, and Linux support
- Optional metadata providers
- More than **1,100 automated tests**

### AI + Deterministic Architecture

VaultDeck can support **AI-assisted classification and enrichment**, while maintaining deterministic classification logic as the reliable fallback.

The goal is to use AI where it improves the experience without making basic functionality dependent on a model or external service.
